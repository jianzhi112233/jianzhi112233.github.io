# 蓝易云 CDN 首页 V9

这是可以直接打开或部署的静态源码，无需安装依赖或执行构建。

## 预览

直接用浏览器打开 `index.html`。图片、脚本和样式均保存在本目录。

正常模式自动播放首屏主题、数据流、视频、GIF 与行业方案。当浏览器启用“减少动态效果”时，页面保持静态，手动切换仍可使用。预览需要明确开启动效时，在地址末尾加 `?motion=on`；`?motion=off` 可检查静态状态。离开可视区域或浏览器进入后台时暂停媒体，GIF 切换为 WebP 海报。

首屏保留三个手动主题按键。核心能力分类手动切换，行业方案约每 7.4 秒自动切换；鼠标停留或键盘操作时暂停行业切换，便于阅读和点击。

## 本版调整

- 核心防护、访问与行为、加速与连接三个分类均使用独立的真实 MP4，静音自动循环，无额外控制按钮。每支影片为 1200×800、30fps、12 秒。
- 修复 ID 选择器覆盖问题，统一所有 12 个能力项的浅灰悬浮背景和持续流光；键盘聚焦也有相同反馈。
- 网站、游戏、金融/支付、高防云服务器四个行业方案全部换成参考图风格的分层架构图。采用真实 HTML/SVG 文字与图标，包含业务接入、六项防护能力、业务服务三个层次。桌面横排，手机竖排；箭头持续流动，行业方案继续自动轮换。

## 继承的调整

- 首屏地球增加 13 条数据流与 12 个脉冲节点，缩放时保持图像和线路对齐。
- 能力项悬浮或键盘聚焦时呈现浅灰底，渐变边框持续循环流光。
- 核心防护区换成真正的 H.264 MP4：1200×800、30fps、12秒、约1.8MB，静音循环，无额外播放、暂停或放大按钮。
- 全球加速图移除底部“用户请求／全球边缘网络／业务源站”标签，加强流动与节点脉冲。
- 高防CDN、WAF、全球加速三个首屏主题及重点标题加入蓝色渐变关键词。
- 四步接入各增加自动循环 GIF；三类线路增加黑色线性图标。

## 素材说明

三支影片的基础画面均来自用户配置的 Packy 图片接口，再以代码合成请求流、攻击粒子拦截、指纹扫描、节点脉冲与服务器扫描，编码为 MP4。它们是能力概念影片，不是机房实拍或后台实录。行业架构图采用可缩放的文字与矢量元素，保证手机文字清晰。

四张接入 GIF 是流程示意，不是实际控制台录屏。example.com、203.0.113.10 为示例值，不是用户业务配置。实际操作请使用页面中的官方教程入口。

本包只包含首页。导航中的独立产品、价格、行业详情等页面仍指向原站，它们的源码未包含在该包中。

## GitHub Pages

将本目录内的 `index.html`、全部 CSS（包括 `architecture.css`）、JS、`brand.webp`、`assets/` 和 `.nojekyll` 放到 Pages 发布目录。`index.html` 应位于发布目录根部。三支 MP4：`server-security.mp4`、`request-intelligence-film.mp4`、`global-delivery-film.mp4`，对应海报与四张 GIF 也需要上传。上传完成后等待 Pages 发布，再刷新页面。本版没有自动更新远程托管站点。

产品详情、注册、套餐及客服链接沿用原站地址。
