# 蓝易云 CDN 自动动效首页

双击 `index.html` 或使用静态服务器打开即可预览。

- 首屏每约 6.2 秒自动轮播，标题、正文和按钮依次淡入淡出。
- 首屏保留“高防CDN / 语义WAF / 全球加速”三个手动切换按钮，暂停按钮已移除；首屏背景节点和光带持续运动。
- 核心能力区域的防护链路、访问识别、线路回源会自动演示。
- 核心能力分类约每 12.4 秒自动切换，也支持点击和键盘切换。
- 行业方案约每 6.2 秒自动轮询网站、游戏、金融/支付与高防云服务器方案，也支持手动切换。
- 误报一键加白提示仍保留，演示区域自动播放。
- 即使浏览器启用“减少动态效果”，本预览仍按需求默认播放动效。
- 若需要关闭本页自动动效，可在地址后加 `?motion=off`。

原有 SEO 字段、标题、正文、外部链接和品牌素材均保留。正式上线前请按原项目要求移除预览环境中的 `noindex,nofollow` 设置。
